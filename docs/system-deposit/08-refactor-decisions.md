# 重构决策记录

本文档记录重构前已经明确的工程决策。后续如果改变决策，应补充新的记录，不要直接覆盖历史结论。

## ADR-001：后端语言暂不切换

状态：已决策。

决策：后端继续使用 Python + FastAPI。

原因：

- 当前系统大量能力与 Python 生态强相关，包括爬虫、Excel、数据清洗和后续预测。
- 当前主要问题是系统边界和数据模型，不是语言能力不足。
- 切换语言会放大重构风险，并且不能自动解决配置、schema、接口、采集链路混乱。

影响：

- 第一阶段不引入 Java/Spring Boot 或 Node 重写。
- 可以调整 Python 运行版本和项目结构。
- 如未来需要企业级权限或更复杂后台，可以再评估 API 层拆分，但采集/清洗仍建议保留 Python。

## ADR-002：查询 API 不触发采集

状态：已决策。

决策：正式查询接口只读取数据库，不同步调用外部网页、公众号、搜狐等 connector。

原因：

- 查询响应时间和外部站点状态绑定会导致用户体验不稳定。
- 查询参数和采集结果日期可能不一致。
- 采集失败不应影响已有数据查询。

影响：

- `/api/prices` 第一阶段应移除 connector 回退。
- demo 模式如需模拟数据，必须显式开启，不能混入正式查询。
- 采集能力后续通过任务或脚本写入数据库。

## ADR-003：目录数据只有一个前端来源

状态：已决策。

决策：前端所有页面只通过后端目录 API 获取鱼种和市场。

原因：

- 当前 `frontend/public/config.yaml` 和 `backend/app/config.yaml` 已经出现内容差异。
- 前端静态配置会导致图表页和录入/导入页使用不同口径。

影响：

- `ChartView.vue` 需要移除 `/config.yaml` 读取。
- 后端目录 API 在数据库不可用时的行为必须明确。
- YAML 可以作为数据库种子，但不能作为前端运行时权威目录。

## ADR-004：导入解析放到后端

状态：已决策。

决策：Excel 和 CSV 都由后端解析、校验和持久化。

原因：

- 前端 `split(',')` 无法可靠处理 CSV 编码、引号、逗号和错误行。
- 后端需要保留导入批次和失败明细。
- 导入规则应与手工录入、采集入库共用校验逻辑。

影响：

- 新增或重构 ImportService。
- `/api/import/excel` 可以先保持兼容。
- CSV 需要新增后端导入路径或统一成 `/api/imports`。

## ADR-005：第一阶段保持接口路径兼容

状态：已决策。

决策：第一阶段尽量保留现有 API path，先替换内部实现和文档。

原因：

- 前端已经依赖现有路径。
- 先稳定行为比改路径更重要。
- 路径迁移可以在服务层稳定后做。

影响：

- `/api/prices`、`/api/prices/batch`、`/api/import/excel` 先保留。
- `/api/fishes` 和 `/api/fishes/list` 的收敛要单独做兼容方案。

## ADR-006：单位和日期口径必须显式化

状态：已决策。

决策：价格单位、价格日期、发布时间、采集时间、入库时间必须分开定义。

原因：

- 当前 UI 文案、接口默认值和模板示例存在“元/斤”和 `kg` 的混用。
- 爬虫提取的文章日期、请求日期和入库时间不是同一个业务概念。

影响：

- 重构价格表时应明确 `quote_date`、`published_at`、`collected_at`、`created_at`。
- 入库时保留原始单位和标准化单位。
- 图表展示的单位必须来自接口返回或全局口径配置。

## ADR-007：先治理底座，再拆大页面

状态：已决策。

决策：第一刀先做环境、配置、schema、接口行为治理，不先拆 `ChartView.vue`。

原因：

- 如果目录、价格查询和单位口径不稳定，拆前端页面会引入更多重复适配。
- 后端契约稳定后，前端拆分可以更干净。

影响：

- 前端第一阶段只做必要的数据来源统一。
- 大规模 UI 组件拆分放到后续阶段。

## ADR-008：非民众渔业数据默认不可信

状态：已决策。

决策：在重构和迁移过程中，除“民众渔业”来源数据外，其他历史价格数据默认视为待校验或高风险数据。

原因：

- 用户补充业务判断：其他来源数据可能都有问题。
- 数据库快照已显示非民众渔业数据存在明显质量风险，包括单位混合、同日多价格点跨度过大、来源缺失、目录口径漂移。
- 如果直接把这些数据作为可信曲线，会污染后续分析和重构验证。

影响：

- 目标价格模型必须有可信度或质量状态字段。
- 图表查询默认只展示可信或候选可信数据。
- 非民众渔业数据迁移时应保留，但标记为 `unverified`、`suspect` 或进入隔离表。
- 鲈鱼、黄颡鱼等历史数据需要独立校验流程后才能进入正式曲线。
