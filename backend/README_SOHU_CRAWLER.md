# 搜狐网鲈鱼价格数据采集系统

## 概述
从搜狐网采集湖州地区加州鲈鱼历史价格数据（2020 年至今）

**数据源：**
- 水产前沿 - 每周价格周报
- 杰大饲料 - 每周行情分析

**目标地区：** 浙江湖州
**目标规格：** 8 两为主（包括 8 两上、8 成大鱼、统货等）

## 快速开始

### 1. 收集历史文章链接

编辑 `sohu_historical_urls.txt` 文件，添加搜狐网历史文章链接。

**搜索方法：**
```bash
# Google 搜索
site:sohu.com "加州鲈" "湖州" "水产前沿"
site:sohu.com "加州鲈" "湖州" "杰大饲料"

# 百度搜索
site:sohu.com 加州鲈 湖州
site:sohu.com 水产前沿 周报
```

在搜索工具中选择时间范围：2020 年 -2024 年

### 2. 运行采集脚本

```bash
cd /Users/zcy/IdeaProjects/fish-price-platform
source venv/bin/activate

# 一键执行全流程
python backend/run_sohu_import.py
```

### 3. 查看结果

采集的数据会保存到：
- `docs/sohu_price_data_to_verify.md` - 原始数据
- `docs/sohu_verification_report.md` - 验证报告

## 数据格式

采集的数据包含以下字段：

```python
{
    'date': '2023-03-29',           # 日期
    'location': '浙江湖州',          # 地区
    'fish_type': '加州鲈',          # 鱼类
    'specification': '8 成统货',     # 规格
    'price': 8.5,                   # 价格（元/斤）
    'price_range': '8.5 元/斤',     # 原始价格文本
    'source_url': 'https://...',    # 来源 URL
    'source_type': '搜狐网',        # 数据来源
    'title': '文章标题',            # 文章标题
    'original_text': '...'          # 原始文本
}
```

## 手动采集 URL 指南

### 步骤 1：访问搜索引擎

推荐使用 Google 搜索（结果更准确）

### 步骤 2：输入搜索查询

```
site:sohu.com "加州鲈" "湖州"
```

### 步骤 3：设置时间范围

在搜索工具中选择：
- 起始时间：2020 年 1 月 1 日
- 结束时间：2024 年 12 月 31 日

### 步骤 4：筛选文章

选择符合以下条件的文章：
- ✅ 标题或内容包含"湖州"
- ✅ 包含价格表格或价格数据
- ✅ 来自"水产前沿"或"杰大饲料"
- ❌ 排除纯广告和新闻资讯

### 步骤 5：复制链接

将筛选后的文章链接复制到 `sohu_historical_urls.txt`，每行一个：

```
https://www.sohu.com/a/516858961_210667
https://m.sohu.com/a/660709304_210667/
```

## 故障排除

### 问题 1：采集失败
检查网络连接和虚拟环境：
```bash
source venv/bin/activate
python -c "import requests; print('OK')"
```

### 问题 2：日期提取失败
搜狐网文章的日期可能不在固定位置，爬虫会尝试多种方法提取。如果仍然失败，会使用当前日期。

### 问题 3：数据重复
爬虫会自动去重，但如果同一篇文章有多个价格数据（如不同规格），都会保留。

## 数据导出

采集的数据可以通过以下 API 查询：

```bash
# 查询湖州地区所有数据
curl "http://localhost:8080/api/prices?market_id=103&fish_id=1"

# 查询特定年份
curl "http://localhost:8080/api/prices?market_id=103&fish_id=1&start_date=2023-01-01&end_date=2023-12-31"
```
